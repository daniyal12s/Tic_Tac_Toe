# 🎮 Tic Tac Toe Game - Python

A simple and modern 2-player Tic Tac Toe game developed using Python and Tkinter.

This project was developed as part of my Week 4 Python Internship at Skillify.

## 🚀 Features

- 🎮 Two-player Tic Tac Toe
- 🔵 Blue X and 🔴 Red O
- 👤 Custom player names
- 📊 Scoreboard for both players
- 🤝 Draw counter
- 🏆 Automatic winner detection
- 🤝 Automatic draw detection
- 🔄 Automatic new round after Winner/Draw
- 🔁 Restart game option
- 🔃 Reset scores option
- 🎨 Modern dark-themed GUI
- 🔄 Current player turn indicator
- 🖥️ Desktop-based application

## 🛠️ Technologies Used

- Python
- Tkinter
